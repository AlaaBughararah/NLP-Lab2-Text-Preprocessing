# NLP Lab 2: Text Pre-processing and Regular Expressions

This repository contains my work for Lab 2 on Text Pre-processing and Regular Expressions in Natural Language Processing (NLP).

## Topics Covered
- Regular Expressions (Regex)
- Text Tokenization
- Lower Casing
- Stemming
- Lemmatization
- Stop Words Removal
- NLTK
- spaCy

## Lab Tasks
- Extracting hashtags from Twitter data and identifying the top 10 hashtags
- Using `re.compile()` for pattern matching and replacement
- Using `re.split()` to split text based on regular expressions
- Tokenization using spaCy and NLTK
